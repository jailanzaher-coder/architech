# ArchiTech VS Code Project

This is the editable source-code version of the ArchiTech website.

## Open in VS Code
1. Extract this ZIP.
2. In VS Code choose **File → Open Folder**.
3. Select `ArchiTech_VSCode_Project`.
4. Open `index.html`.
5. For the best experience, install the **Live Server** extension and click **Go Live**.

## Files
- index.html
- about.html
- technology.html
- login.html
- signup.html
- workspace.html
- styles.css

No npm, React, or build step is required.
